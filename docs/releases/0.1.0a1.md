# LudoWeave Engine 0.1.0a1

This community-alpha candidate proves the complete M0-M6 loop: deterministic
headless world operation, typed commands/receipts, snapshots/replay, isolated
2D WebGPU presentation, Clockwork Arena, and capability-gated local agent tools.

The baseline wheel is pure Python and requires no compiler, graphics package,
display, or network listener. WebGPU presentation remains an exactly locked
optional extra.

The installed evaluation surface also includes explicit-factory conformance
profiles for render devices, the transport-independent agent tool service, and
storage-neutral `WorldStore` implementations. Project-owned passes are
reference evidence rather than third-party certification or adoption.

M20's installed command/receipt readiness evidence retains those central
contracts as experimental under RFC-0003. It adds no runtime or wire-format
change and makes no cross-version or external-adoption claim.

M21 adds an experimental, resource-bounded public reader for the existing
`ludoweave.receipt/1` shape and freezes exact same-version committed, dry-run,
and rejected fixtures under RFC-0004. It does not change the receipt protocol,
prove cross-version compatibility, or promote any API.

M22 records an exact compatibility policy for the seven built-in operation-v1
argument shapes and exercises valid, missing-required, and unexpected-field
behavior from installed artifacts under RFC-0005. It adds no operation or
runtime schema and does not prove cross-version compatibility or promote any
API.

All Python APIs and persistent protocols in this alpha are `experimental`.
Read `API_COMPATIBILITY.md`, verify `SHA256SUMS`, inspect the SPDX SBOM and
notices, and verify the GitHub artifact attestation before using an official
tagged artifact.

Known limitations and deferred work include promotion of any API beyond
experimental stability, remote/network
transport, production audio, rigid-body physics, visual-editor tooling,
automatic GPU
recovery, rich text/animation, 3D, and native acceleration. The recorded M1 and
M3 performance target misses remain profiling evidence rather than release
claims.
