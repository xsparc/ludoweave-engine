# LudoWeave Engine 0.1.0a1

This community-alpha candidate proves the complete M0-M6 loop: deterministic
headless world operation, typed commands/receipts, snapshots/replay, isolated
2D WebGPU presentation, Clockwork Arena, and capability-gated local agent tools.

The baseline wheel is pure Python and requires no compiler, graphics package,
display, or network listener. WebGPU presentation remains an exactly locked
optional extra.

All Python APIs and persistent protocols in this alpha are `experimental`.
Read `API_COMPATIBILITY.md`, verify `SHA256SUMS`, inspect the SPDX SBOM and
notices, and verify the GitHub artifact attestation before using an official
tagged artifact.

Known limitations and deferred work include promotion of any API beyond
experimental stability, remote/network
transport, production audio, rigid-body physics, editor tooling, automatic GPU
recovery, rich text/animation, 3D, and native acceleration. The recorded M1 and
M3 performance target misses remain profiling evidence rather than release
claims.
